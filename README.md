# Joltr

**Capture what moves you the moment you see it. Joltr organizes and finds it for you.**

Joltr is a private Mac library for everything that inspires you: posters,
interfaces, type, color, anything you see on your screen. Capture it or drop it
in, and Joltr reads the text inside it so you can find it by what it says. It
all stays in a folder on your own machine.

[**Download for macOS**](https://github.com/rosanusi/joltr-releases/releases/latest) · macOS 11 or later · Apple Silicon and Intel

Open the `.dmg` from the latest release and drag Joltr into Applications.
Joltr is in public beta and free while it is. It updates itself when a new
version is out.

## What it does

- **Capture** — `⌘⇧1` for the full screen, `⌘⇧2` for a region. Screenshots and
  copied images land in your library on their own.
- **Find it by its words** — Joltr reads the text inside every image, on your
  Mac, so a line you remember is enough to find it.
- **Named and tagged** — add a free Google Gemini key and every image gets
  tags, a description and a proper name. Optional.
- **Folders, tags and colors** — group by project, filter by tag, and copy
  the main colors of any image.

## Privacy

Your library lives in a folder you choose. There is no account, no sync and
no Joltr server.

- Text recognition, color extraction and search all run on your Mac.
- If you add a Gemini API key, the images you import are sent to Google's
  Gemini API for tagging. Without a key, no image leaves your Mac.
- On launch, Joltr asks GitHub whether a newer release exists.
- No analytics, telemetry or crash reporting.
